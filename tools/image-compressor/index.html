Frequently Asked Questions

How does client-side image compression work?

Image compression is rendered using HTML5 Canvas APIs. The image is drawn onto an offscreen canvas element and exported with custom lossy or lossless compression levels.

Are my pictures uploaded to a cloud server?

No. The canvas processing happens entirely in your local browser memory. No network uploads take place.

Which image formats are supported?

Cipher Image Compressor supports standard web formats including JPEG, PNG, and WebP.
